# 闲置互动

把 MP4 放在此目录：一段固定播放，多段随机选择。目录为空时不会触发。

默认规则：Windows 当前会话连续 15 分钟无键鼠输入后进入待播；回来后继续移动鼠标或点击，只会重新计算安静时间。停下约 2 秒、Codex 在前台且没有其他动画时，完整覆盖 Codex 窗口播放一次。回来后最多保留 60 秒机会，避免很久以后突然打断工作。播放开始后，继续输入、最小化 Codex、打开其他片头或播放结束都会收起。可在“Codex 片头助手”托盘菜单关闭或手动预览。

此功能只读取上次输入的时间，不读取键盘内容或鼠标位置，不保存活动历史。个人视频默认不纳入 Git；公开新素材前请单独确认授权。
