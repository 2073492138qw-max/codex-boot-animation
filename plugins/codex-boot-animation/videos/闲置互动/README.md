# 闲置互动

把 MP4 放在此目录：一段固定播放，多段随机选择。目录为空时不会触发。

当前规则（人性化陪伴模式）：
- 前台发呆：Codex 在前台且连续 5 分钟无键鼠输入时，主动播放一次互动动画。
- 冷落回归：在浏览器/微信等其他软件里连续忙满 10 分钟未切回 Codex，回到 Codex 前台停顿约 0.8 秒后播放一次迎接动画。
- 离座/休眠回来：整机连续 5 分钟无输入，回来后 5 分钟内切回 Codex 前台并停顿约 0.8 秒即触发。
- 防手抖与防刷屏：开播前 1.2 秒不会因手抖误关，之后继续操作或切出 Codex 会自动收起；每次触发后冷却 15 分钟。

此功能只读取上次输入时间和前台窗口归属，不读取键盘内容或鼠标轨迹，不保存活动历史。
