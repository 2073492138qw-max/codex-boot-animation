# 视频文件夹

把 `.mp4` 放进对应场景的文件夹，不要放在本目录根部：

- `冷启动/`：完全退出后重新打开 Codex
- `新聊天/`：点击新聊天
- `生气回应/`：对 Codex 直接表达强烈不满
- `任务完成/`：明确任务完成后的窗口内动画
- `闲置互动/`：电脑闲置 15 分钟后，回到 Codex 且停止输入约 2 秒时，只覆盖 Codex 窗口播放一次；再次操作会立即关闭

每个场景只读取自己的文件夹。一段视频就固定播放，多段就在该场景内随机播放；
空文件夹只关闭该场景。复制或删除完成约 1.5 秒后自动重新扫描，也可以右击
“Codex 片头助手”托盘图标点“重新扫描视频”。`未启用素材/` 中的视频不会播放。

当前源码收录五类场景和备用目录共 15 个视频路径，清单见 `media-catalog.json`；
已冻结的 0.7.0-alpha.5 ZIP 仍包含原来的 11 段视频，没有重新打包。
清单内视频及同名首帧图按 `LICENSE.md` 的 CC BY 4.0 授权发布。
冻结 ZIP 的冷启动目录只有红色警戒兔耳；源码目录另含已授权的备用视频。

也可运行仓库根目录的 `scripts/Add-Video.ps1`。如果安装了 FFmpeg，脚本会为
`example.mp4` 提取 `example-first.png`；没有首帧图片也能播放，只是在新画面
解码前显示黑色遮罩，不会闪出上一段视频的尾帧。
`任务完成/` 的首帧图也会用于填充视频与窗口比例不同时的模糊背景。

新放入且不在清单内的个人视频默认不会被 Git 提交，避免
未经确认就公开素材；确认授权后可显式加入版本管理。
