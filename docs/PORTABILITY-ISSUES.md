# 历史问题与其他电脑部署风险清单

日期：2026-09-30。依据：本对话的用户反馈、CHANGELOG、HANDOFF、INSTALLATION、RELEASE。
用途：交给新对话制定修复与验收计划；不是证明所有历史问题仍存在，也不是跨电脑故障率统计。

## 核心判断

其他电脑可能遇到同类问题，但不能说一定遇到或给出发生概率：目前没有独立第二台电脑的完整验收。
本机确认正常的行为应保持；已修复问题加入回归测试，不重新推翻播放器。
当前项目是 Windows 原生伴随助手加 Codex hooks，不是直接嵌入 Codex 的视频播放接口。
插件安装成功、hooks 可信任、Windows 常驻助手正常和素材可解码，是不同验收项。

编写本清单时另一个对话正在修改安装流程与 alpha.3；动手前检查 Git 状态，不覆盖其改动。
2026-10-01 接续成果及仍待真实验收的项目见 `VALIDATION.md`。本清单保留历史问题，
不作为最新测试结论；清单本身不改 EXE、启动项、媒体或信任状态。

## 一路遇到的问题

| 编号 | 用户实际遇到的现象 | 目前已知处理/状态 | 其他电脑的风险 |
| --- | --- | --- | --- |
| H01 | 最早 DeepSeek Harness 插件加载失败，等待 uiSession，网页卡住 | 属于此前 DSH 插件阶段，不是当前 Codex 助手的同一触发机制；仅凭截图不能确定全部根因 | DSH 的 profile/依赖问题不要直接照搬进 Codex；两个产品分开诊断 |
| H02 | 切换片头不生效，每次还是同一个 | 当前改为场景独立目录、单段固定、多段随机、变更重扫 | 修改了源码/缓存/实际安装中错误的目录，仍可能看不到变化 |
| H03 | 没声音；要点击或全屏才有声音；停在“点击播放” | 前期是浏览器播放路径；当前使用原生 WPF 播放，声轨和正常播放本机确认 | 音轨缺失、视频编码不兼容、系统应用静音/设备不同仍需检查；不能把浏览器策略当作所有原因 |
| H04 | Codex 没动画、要发送消息才触发、点击新聊天延迟 | 改为常驻预载和鼠标点击快路径；用户曾确认点击立即覆盖 | Codex 界面/语言变动、键盘新聊天、性能或识别失败退到日志兜底会变慢；不能保证绝对零延迟 |
| H05 | 播一次后再新聊天不播；完全退出重开不播 | 独立 supervisor/watch/resident 与进程实例检测；本机曾确认连续新聊天可播 | 助手崩溃/未启动、旧进程残留、版本冲突仍可能导致不播 |
| H06 | 关机重启之后所有触发失效 | 增加当前用户登录自启动与进程实例去重；最新跨电脑/真实重启验收仍待完成 | 高优先级：路径迁移、启动项被关闭、打包进程注册表视图、登录启动时序 |
| H07 | 右键 Codex 托盘退出菜单也误播；重开播放两遍 | 排除托盘动作；快路径与日志兜底去重；用户分别确认不误播、重开一次 | 新版本布局和启动竞争仍需真实验证，不应通过扩大触发范围修复 |
| H08 | 开头闪出后段人物，再从头播 | 寻址归零并使用首帧遮罩；用户确认顺序正常 | 新增视频无首帧、替换视频却留旧首帧、不同解码器需回归 |
| H09 | 改启动后出现“ChatGPT failed to start，该进程没有程序包标识符” | 历史启动路线曾导致此报错；不能仅凭截图断言全部内部原因 | 不允许靠修改/直接启动错误应用包内部入口实现；当前路线应不修改 Codex 本体 |
| H10 | 生气回应有声音却显示冷启动画面；第一次无画面，第二次不播/延迟 | 场景层隐藏/静音隔离、重复触发与冷却处理；用户后续确认两次有画面和声音、触发变快 | 预载对象生命周期、切场景、媒体失败和忙时优先级需回归 |
| H11 | 生气视频被加速，不自然 | 生气、完成、闲置 1.0×，启动/新聊天 1.2×；用户确认生气原速 | 场景设置不能共用一个速度覆盖全部场景 |
| H12 | 完成动画无触发，长任务也漏；预览成功但真实结束不成功 | 新增续跑状态继承、简短请求识别、长任务 journal 兜底、完成措辞修复；重放真实约 23 分钟记录通过，用户确认画面声音正常 | 高优先级：hook 未信任/未执行、Codex 内部日志变化、续跑、规则误判；手工预览不能证明任务触发有效 |
| H13 | 动画提前消失、完成通知只在点回 Codex 后出现 | 窗口归属/焦点处理曾修复；完成当前最多等待前台 90 秒 | Windows 前台限制、多窗口识别、自有播放器焦点、切出后超时等；“不遮别的软件”与“立即播放”存在策略取舍 |
| H14 | 完成视频黑边不舒服；闲置小窗太小、半秒就消失 | 全 Codex 窗口、完整比例与暗化模糊背景；用户确认舒适 | 多屏、DPI、不同宽高比、窗口移动/缩放仍待独立验证 |
| H15 | 闲置只预览能播，实际没见触发 | 当前定义为 15 分钟无输入后返回、安静 2 秒、前台非忙、60 秒机会；修改返回输入防抖 | 用户不知道触发条件；持续输入/后台/任务忙可能正常不播，也可能策略缺陷；需区分 |
| H16 | 想所有声音一样大 | 当前各场景应用音量 65%，另有非破坏性音频响度处理脚本 | 相同音量滑块不等于相同主观响度；新 MP4、扬声器、系统混音不同需检测 |
| H17 | 安装、信任、重启、视频位置不清楚；要换电脑方便部署 | alpha.3 增加真实钩子发现闸门、活动安装诊断、安装等待和回滚；详见 VALIDATION | 对普通用户最难的是看不见哪一步失败，以及不知道该改哪个目录 |

## 别人安装后最困难的事项（建议顺序）

优先级不是发生率。P0 是阻止基本使用/部署的门槛，P1 是主要行为可靠性，P2 是易用性。

| 优先级 | 难点 | 应交付的改进或核对 | 可验收标准 |
| --- | --- | --- | --- |
| P0-1 | “装了但完全没反应”，不知道安装是否成功 | 检测 Windows/.NET/WPF、Codex 包和 CLI、文件完整性；分别展示插件安装、hook 信任、助手运行结果；给出具体下一步 | 新用户在无管理员、中文/空格路径下能安装；缺依赖、拒绝信任、被安全软件阻拦时有准确解释，不要求关闭安全软件 |
| P0-2 | 重启电脑或完全退出 Codex 后不触发 | 核查正常 Windows 环境的当前用户自启动、持久路径、启动竞争、助手恢复和进程实例去重 | 独立电脑真实重启，再冷启动一次；每次仅播一次，新聊天连续两次可播；托盘退出不误播 |
| P0-3 | 任务结束没有动画，而预览可以 | 分别诊断候选请求、Stop/journal、续跑、最终结果、去重、通知和前台等待；可视化说明抑制原因 | 真实短任务、长任务、自动续跑能按约定触发；问候/失败不播，重复通知不重复播；后台等待与超时能解释 |
| P0-4 | 安装/升级后修改的不是正在用的文件 | 明确唯一活动根目录；诊断源目录、安装目录、缓存版本和运行 EXE；安全更新与回滚 | 在源、缓存不同且用户有新增视频时升级，个人视频保留，无双助手、无旧 EXE 意外接管，卸载只移除自身注册 |
| P1-1 | Codex 更新/界面语言变化导致新聊天无效或变慢 | 检测支持的包身份和按钮；记录快路径/兜底原因与真实延迟；失败时可诊断降级，不打补丁到应用包 | 测中英文、鼠标/键盘新聊天、不同窗口尺寸；明确键盘兜底差异，不承诺零延迟 |
| P1-2 | 换视频后黑屏、静音、旧首帧或错误场景 | 识别可解码性、音轨、损坏文件/复制未完；替换视频后避免旧封面；场景不跨目录兜底；给出失败路径 | 有效 MP4、新视频无封面、损坏文件、无音轨、不同宽高比都有确定处理；其他场景仍正常，播放器不会永久挡住工作 |
| P1-3 | 多屏或焦点导致遮错窗口、突然消失 | 验证 Codex 窗口归属、活动播放器、DPI、多屏边界、缩放/最小化；禁止抢其他应用前台 | 100%/150%/200% DPI 和双屏移动时只覆盖目标；失焦策略符合每场景约定 |
| P1-4 | 连续操作/场景争抢时重复播或音画串台 | 回归快路径加日志兜底、跳过再触发、怒气连续消息、任务结束与闲置同时发生、文件库刷新 | 每个接受的事件至多一次；没有旧画面叠新声音、永久不再触发、播放器累积；忙时抑制可查 |
| P2-1 | 闲置没触发却不知道是不是坏了 | 提示阈值、倒计时/前台/忙状态、播放机会到期原因；不记录输入内容 | 真实 15 分钟闲置回归与预览分开验收；活动时不打断，返回后只一次 |
| P2-2 | 音量、速度、目录和素材管理难懂 | 中文场景入口、清楚的“单个固定/多个随机”、音轨/响度说明、每场景速度与静音选项 | 不改代码即可管理素材；不用猜实际路径；音频归一化保留原文件且用户可撤销 |

## 实施约束与建议测试矩阵

- 先读 HANDOFF、检查其他对话的 Git 改动，再制定最小修复；不改已经本机验收正常的行为。
- 不删历史状态来伪造测试通过，不从预览推断真实任务事件成功，不把日志送达当作用户看到听到。
- 不修改 Codex/ChatGPT 程序包、不绕过 hook 信任，不关闭系统安全，不强行接管别的启动项。
- 至少增加独立 Windows 账号/电脑的验证；标明 Windows 10/11、Codex 包版本、CLI、语言、DPI、音频设备和测试时间。
- 真实验收：干净安装 → 信任 → 两次新聊天 → 完全退出/重开 → 托盘 → Windows 重启 → 素材替换 → 五种场景 → 升级回滚 → 卸载。
- 新视频与日志默认私人；公开时只保留明确授权素材、匿名摘要和必要脱敏诊断。
- 当前只支持约定的 Windows 打包版路线，不声称 macOS/Linux 或所有 Codex 安装形态可用。

## 给下一个对话的任务

请先完整阅读 `docs/HANDOFF.md` 和 `docs/PORTABILITY-ISSUES.md`，并检查其他对话尚未提交的修改。
按上面 P0 → P1 → P2 顺序完善部署可靠性、诊断和验收，不重写已正常播放器。
每项区分历史已修复、当前已复现、仅推测风险和独立电脑尚未验证。
用真实安装/触发链路验证；无法完成独立电脑/真实重启测试时明确记录待办，不能用本机单测代替。
未经新的明确授权，不上传 GitHub，不重启/关机，不改变信任设置。
