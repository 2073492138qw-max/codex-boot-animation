## 问题与最小修改

旧报告主要使用英文事实和处置建议，小白难以判断下一步。“待实测”也容易被理解
为已有功能失败。不是新的播放器故障。本项新增纯显示函数 Diagnostic-Text.ps1，
只读取检查行，输出中文名称/状态/建议和数量汇总。Diagnose.ps1 仅非 JSON 分支
调用它；原有检测段和 JSON 分支未变。未知未来值仍显示原文，不掩盖异常。

check.cmd 去掉重复英文成功结语，保留 ASCII 启动器及缺文件/脚本失败的英文兜底，
避免更改系统代码页。显示成功/无法确认不等于实际播放验收，日志音轨也不等于
扬声器实际有声。START-HERE 和 CHANGELOG 补充说明。Test.ps1 接入独立显示回归。
没有构建 EXE、安装依赖、重装插件、修改缓存信任、改 Codex 本体或改视频。
