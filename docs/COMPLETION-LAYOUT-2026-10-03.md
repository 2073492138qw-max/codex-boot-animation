## 使用

1. 右键 Windows 托盘 **Codex 片头助手**，不是 Codex 自己的图标。
2. 点 **完成提醒设置（位置 / 大小）**。
3. 选择大小和位置，点 **预览当前选择**。预览不保存，不切回 Codex；可能已有
   完成视频在播或没有完成视频时会提示，不能留下等待焦点的队列。
4. 满意再点 **保存设置**，下次后台完成提醒生效。直接关闭不保存。

默认 **大、右下角**，与已验收的旧布局完全一致：工作区宽约 50%，高度最多
55%。中为宽约 40%、高最多 45%；小为宽约 30%、高最多 35%。超宽屏按高度
缩小，保持 16:9 外框；视频自身完整显示，已有比例处理不变。提醒避开任务栏，
使用当前前台显示器的工作区和原 DPI 处理，不添加屏幕选择功能。

点 **填入默认值**后需再保存才恢复默认。预览可以使用未保存的当前选择，仍
遵守任务完成场景的音量/静音设置；关闭该场景自动触发不禁止手动预览。
预览是单独后台样式测试，不是冒充真实任务完成，不改候选和去重记录。与完成
播放器复用原 pending 互斥，已有完成视频时拒绝，避免叠播或延迟补播。

## 保存与隔离

位置：`%USERPROFILE%\.codex-boot-animation\completion-layout.json`。
schemaVersion=1，只接受 size=Small/Medium/Large 和 corner=BottomRight/BottomLeft。
读取上限 4KB，拒绝未知字段/类型/数值字符串/版本。没有文件时保持原默认。

布局存储独立于 `scene-settings.json`，没有迁移或重写原音量文件。保存核对读入
版本，过期窗口不覆盖别人更改；有界互斥、同目录暂存与原子替换，旧版保存于
`settings-backups\completion-layout-<唯一标识>.json`。读取损坏文件时编辑器不
允许保存覆盖；自动完成播放器使用原默认布局、记录错误类型，不因为布局坏了
停止提醒。不会自动修复、删除损坏文件。

只有单次 `--task-play` 在初始化阶段读一次布局，新聊天/冷启动/常驻轮询没有
新增配置读盘或通知等待。每次视频创建后布局固定，保存不改正在播放的提醒。
`--notice-preview <size> <corner>` 是严格校验的手动预览入口，不注册新钩子。
