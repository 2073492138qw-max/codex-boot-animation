# Codex 片头助手 0.7.0-alpha.5

Windows 社区公开测试版，**不是 OpenAI 官方插件，也不是稳定版**。下载与发布状态以本项目 GitHub Releases 页面为准。

## 可以做什么

- 打开 Codex、点击“新聊天”时播放片头，可跳过。
- 可选生气回应、任务完成提醒、闲置互动；不同场景各放各的视频。
- 拖入 MP4 即可替换；一段固定，多段随机，不要求制作首帧图片。
- 分场景调音量、静音、关闭自动触发；后台完成提醒可选大小和左右位置，不抢焦点。

## 下载与安装

需要 Windows 10/11、.NET Framework 4.8，以及能正常打开的 Windows 商店版 Codex。
已有旧安装的人先看[旧安装处理](INSTALLATION.md#existing-installations)，不要安装第二份。

发布附件：`codex-boot-animation-0.7.0-alpha.5-windows.zip`、同名 `.zip.sha256` 和 `.verify.md`。
发布时同时提供最新版[小白安装指南](../START-HERE.md)和[钩子备用操作步骤](INSTALLATION.md#hook-review-fallback)，链接到发布仓库，或按原目录结构另附。已核查的 ZIP 未重打，不能只向安装者提供包内的旧说明。

1. 先打开 Codex，确认聊天页面正常。
2. 右键 ZIP →“全部解压缩”，放到不会再移动、删除的文件夹。
3. 双击解压后的 `install.cmd`，不用管理员权限。看到 **Installation finished** 才继续；看到 **Installation stopped** 就停止，反馈出错的几行。
4. **安装后保留整个解压文件夹。接着完成下面的钩子允许，不能跳过。**

## 最重要：允许这三项钩子

这里的“钩子”是让 Codex 在指定时刻调用本插件程序的权限。**不用写代码，也不用自己制作钩子。安装完成、插件已启用，不等于钩子已允许。**

1. 在 Codex 打开“插件”页面（有些版本在“自定义”里），找到 **Codex Boot Animation**，确认已启用。
2. 出现“钩子 / Hooks”审核时，核对来源是 **codex-boot-animation**，命令调用本插件 `hooks` 文件夹里的 **BootPlayer.exe**。
3. 只审核、信任并启用本插件的以下三项；不要把其他插件或项目一起“全部允许”。

| 审核名称 | 检查报告中的中文名 | 做什么 |
| --- | --- | --- |
| SessionStart | 会话启动钩子 | 助手没运行时尝试恢复 |
| UserPromptSubmit | 消息提交钩子 | 判断生气回应、记录任务类型 |
| Stop | 任务结束钩子 | 判断任务完成提醒 |

允许后，双击解压文件夹里的 **check.cmd**。三项必须分别显示 **通过、已启用：是、信任：已信任**，才确认这一关完成。片头或托盘预览能播不能代替这个检查。

**没有审核弹窗也先运行 check.cmd：** 已信任就不用重复允许；“尚未信任 / 定义已变更”按[备用审核步骤](INSTALLATION.md#hook-review-fallback)操作；没有三项或“无法确认”就反馈相关几行，不反复重装。**不要在桌面聊天框输入 `/hooks`，它只用于 Codex 命令行界面。**

这一步需要安装者按正规入口自己审核，安装器不会替你允许或绕过。[OpenAI 官方审核规则](https://learn.chatgpt.com/docs/hooks)。

## 安装后先确认

保存工作，完全退出 Codex（包括它自己的托盘图标），不要退出片头助手。重新打开应播放一次片头；结束后点“新聊天”应再播放。点“跳过”或按 Esc 可关闭。
生气回应和任务完成需用真实消息、真实任务验证，不是每句话、每次回复都播放。
更换视频和声音设置看[小白指南第 5 步](../START-HERE.md#5-换视频调声音)。
