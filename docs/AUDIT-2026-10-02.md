## 小任务一：导航日志半行丢失

根因：FileSystemWatcher 通知可能在一行写完之前到达；旧版 ReadToEnd 后直接把
文件末尾作为已读位置。第二次写入只剩尾半行，前端就绪/新聊天标记不能再拼回。

修改：独立 NavigationLogReader 只交付有换行符的完整字节段，保留尾部的文件
偏移；文件变短时从零读取。保持原事件识别、去重、鼠标快路径及 UIA 安全门不变。

验证：先将旧读取算法放入同一测试入口，`--navigation-log-test` 退出 22（失败）；
修补后测试覆盖事件每个字节切分、CRLF 切分、UTF-8 中文切分、尾行续写、重复读取、
截断和 UTF-8 BOM。实际画面不在无人值守时宣称验收。

构建成功，20 项非 UI 检查全部通过（16 个 EXE 入口、真实 hook stdin 往返、
3 组安装/回滚检查）；git diff --check 通过。本任务独立提交，随后才开始 IPC 修补。

回退：仅回退本任务提交中的源码/测试并重新构建、使用安全更新脚本。不要恢复
启动事故前的 EXE。完整非 UI 测试结果、实装及后续任务将在本文件追加。

保持打开时，服务端 ReadLine 一直等到断开。没有连接或攻击正在运行的真实播放器。
影响仅为可选动画通知，不将其描述为 Codex 本体冻结或任意代码执行。

修改：ResidentProtocol 集中定义用户 SID + Windows session 的 V2 名称；显式受保护
ACL 只允许当前用户；接入后 1000ms 绝对读取期限、256 字节上限。超时关闭当前连接，
不等待未完成 I/O；客户端与服务端共同更新，不改变合法场景消息或去重规则。

验证：隔离 ACL 检查、静默只读连接期限、旧连接未关闭时重新接入、7 类合法消息
分段发送、字节边界/超限、逐段慢发不延长期限、EOF。协议测试连续重复 8 次通过；
PowerShell 7 和 Windows PowerShell 5.1 各 21 项非 UI 检查通过，构建与 diff 检查通过。

## 小任务三：日志初始化也要保留未完成尾行

继续检查任务一的边界时发现：助手初次建立监听仍用文件长度初始化偏移，会跳过
已经开始写、尚未写完的最后一行。没有据此调整 UIA 或触发时机。

先增加同一入口的启动测试，旧初始化行为退出 22；改为倒序 4096 字节块扫描，
从最后一个换行符后开始监听。完整历史行不重放，尾半行能等后续写完再识别；
初始化不把完整历史文件装入内存。新增每个切分位置、完整历史行和空文件检查。

扩展复测曾暴露测试器自己的竞争：EOF 客户端在测试工作线程进入接受前已断开，
Windows/.NET 返回 IOException。生产服务已有异常接入恢复，但测试入口未捕获导致
测试进程退出，并非正在运行的 Codex 或助手崩溃。只调整测试器：连接前注册异步
accept，异常明确记失败，绝不吞错报成功。新增跨 4096 字节块的尾行边界复测。

最终测试器连续 20 次协议检查全部通过；最终版本在 PowerShell 7 和 Windows
