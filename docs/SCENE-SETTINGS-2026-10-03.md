## 怎么用

1. 右键 Windows 托盘的 **Codex 片头助手**（不是 Codex 自己的托盘图标）。
2. 点击 **场景设置（音量 / 静音 / 开关）**。
3. 在冷启动、新聊天、生气回应、任务完成、闲置互动五行中单独修改。
4. 点击 **保存设置**。直接关闭不保存；**填入默认值**也必须再保存才生效。

自动触发默认开启、默认不静音，冷启动默认 85%，其余默认 65%。原闲置关闭
标记存在且还没有新设置文件时，仅闲置默认关闭。之后闲置托盘快捷开关和本
窗口使用同一设置，避免两个开关相互抵消。

关闭自动触发不禁止该场景的手动预览；预览仍使用这一行的静音和音量。原来的
总暂停仍优先于自动触发，手动预览的原有行为保持。重新启用不会补播此前已
忽略的启动、点击或完成事件。

修改不会打断已经在播的视频，从下一段读取新值。片头上的临时声音按钮只
影响当次播放，下一段仍按已保存值。音量 0 和静音都可以无声；100% 是播放器
上限，不是系统音量，也不能保证不同原片的实际响度相等。

冷启动/新聊天速度仍为 1.2，生气/完成/闲置仍为原速；视频目录、随机规则、
播放位置、跳过、预加载和场景优先级没有改变。无需重做视频或补首帧图。

## 保存和兼容性

设置在 `%USERPROFILE%\.codex-boot-animation\scene-settings.json`，不在 Codex
应用目录、插件缓存或公开源码中。同一 Windows 用户/会话内的活动助手和缓存
兜底播放器都读取共享目录，不依赖被打包环境重定向的 AppData。

JSON schemaVersion 为 1，固定五个英文场景键，每个仅有 `enabled`、`muted`、
`volumePercent`。音量必须是 0–100 整数，读取限制 8KB。播放热路径只读内存
快照；文件读取由初始化、保存通知或后台文件通知触发，不添加点击读盘。

保存前核对版本，多个设置窗口冲突时提示重新打开，不覆盖另一个窗口的新值。
保存用有界互斥和同目录暂存/原子替换；失败不宣称生效。替换前版本保存在
`settings-backups\scene-settings-<唯一标识>.json`，首次创建没有旧版可备份。
首次读取损坏文件会停用自动场景；运行中读取失败保留上次有效快照，不偷偷改
原文件。旧 `idle-disabled` 标记保留，存在有效新 JSON 时不再作为第二个开关。

## 回退

优先在窗口恢复所需开关/静音/音量并保存，而不是删除个人设置。若需要二进制
回退，先检查 Git 状态和本轮之后的新设置，退出本助手并确认进程停止，再从
上述两个私有备份分别恢复活动/缓存 EXE，启动活动助手；不要关闭 Codex、覆盖
正在运行的 EXE 或覆盖视频。旧版不会读取新 JSON，新 JSON/备份保留不删除；
旧闲置标记再次成为旧版的闲置开关，需告知用户这个兼容差异。

源码回退以本项独立提交为单位，未提交阶段不使用 reset/checkout 覆盖工作区。
配置备份恢复属于覆盖个人设置，另行确认具体备份；不要拿测试夹具替换真实 JSON。
